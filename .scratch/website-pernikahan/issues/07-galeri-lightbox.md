# 07: Galeri + lightbox

**What to build:** Tamu menikmati galeri foto prewedding dengan perilaku scroll sesuai score. Tamu bisa mengetuk foto untuk memperbesarnya, berpindah antar foto, lalu menutupnya.

**Blocked by:** 04 (Buka Undangan, lalu Hero berlapis + musik)

**Status:** ready-for-agent

**Category:** enhancement

- [ ] Device galeri sesuai score. Gambar dioptimasi dan dimuat lazy.
- [ ] Lightbox:
  - [ ] terbuka saat foto diketuk,
  - [ ] bisa digeser dengan sentuhan dan punya tombol sebelumnya/berikutnya,
  - [ ] tertutup dengan Esc atau klik latar,
  - [ ] mengunci scroll body selama terbuka,
  - [ ] menjaga fokus keyboard tetap di dalam lightbox,
  - [ ] mengembalikan fokus ke foto asal saat ditutup.
- [ ] Setiap foto punya teks alternatif.
- [ ] Komposisi mobile dan mode reduced-motion tetap lengkap.
- [ ] E2E: buka lightbox, pindah ke foto berikutnya, lalu tutup dengan Esc.
